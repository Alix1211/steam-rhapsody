# 개그 메모 (케인 제안, 해당 장에 맞춰 반영)

## 1. 오크 주인 × 인간 여성 노예 (남성국 줄기 M1~M3 후보)
케인 원문:
- 주: 그렇게 굳을 필요 없어요.. 난 생각보다 거칠지 않다구.. 어서 이리 오세요
- 노: 저…는 사람이구요.. 그쪽은 오크이신데.. 「사이즈」가 다른데… 거칠지 않다구요?
- 주: 응? 사이즈? 이거 말인가???…
- 노: 털썩(기절했음)
- 주: 대장!!! 오크!! 오크 여성 좀 잡아달라구요!!!!! 제발… 이번 달 벌써 몇 명째냐구요!!!!

반영 방침(가안): 제국 오크 용병대원 NPC + 대장 그로크. 「이번 달 기절 포로 수」 반복 개그. 핀 사이즈 개그.
사이즈는 끝까지 구체적으로 말하지 않는다(암시형).

## 2. 족쇄 위치 (F1 6편에 반영 완료)
- 톰: 근데 꼭 「여기」 묶으실 필요가 있습니까
- 아네트: 「거기」가 잡기 편해서요

## 3. 정화 시퀀스 콜 (남성국 줄기 M1 이후 반복, 여성국 줄기에는 거울 구조로)
케인 원문:
- 남주: 오늘도 어김없이.. 정화 시퀀스다!! 긴장하는 게 좋을 거다 암노예들아!!!
- 여노: 네~~~~~~~~~~~~~~~~~~!! 하트 뿅뿅..
- 남주: 어.. 이거 왜 이래.. 이봐!! 겁먹으란 말이다.. 내 손에 들린 이 무시무시한 기구가 안 보이냔 말이다!!
- 여노: 보이죠!! 그래서 기분 좋아진 건데.. ㅋㅋㅋ 어서 가죠! 정화방...

반영 방침(가안): 장마다 오프닝 콜로 반복, 노예들의 반응은 갈수록 신나게, 주인은 갈수록 당황. 여성국 줄기에서는 렌·톰·카이단·그로크가 같은 구조(부정 → 인정).

## 4. 순응 곡선 (케인 방향 + Claude 가안, 두 줄기 공통)
케인 방향: 남이든 여든 몇 화 지나면 지나치게 순응하거나, 인물에 따라 끝까지 저항은 하지만 얼굴이 달아오르고 부르르 떤다(겁이 아니라 흥분 쪽). 두 팀 모두 막판에는 전쟁인지 에로 놀이인지 모호해진다.

장별 단계: 1장 당황·저항 → 2장 몸이 먼저 정직 → 3장 습관 → 4장 기대 → 5장 구분 불가
인물별 유형(가안): 렌=끝까지 저항(부정하며 떪) / 톰=일찍 순응(담요→초커 먼저 챙김) / 카이단=본능형(꼬리가 정직) / 그로크=적극형 / 로제=능청형 / 핀=저항형(소리치며 도망, 얼굴 빨강) / 벨루가=자유분방형 / 자하라=계산형(흥정)
5장 보스전: 구속 대전 연출, 양쪽 병사 모두 포획되면 기뻐서 전선이 흔들림 → 11장 연합의 "누가 누구를 정화하나" 코미디로 연결.
떠는 것은 대사에서 오해로 풀린다(「추워서」「배고파서」 등).
