# GENDER WARFARE — 슈팅 게임

개인 놀이용 니케풍 3인칭 뒷모습 슈팅 프로토타입. 스팀펑크 행성 발부르기스에서 여존 연방 도미나리아(빨강·금·흰색)와 남존 제국 발할리온(검정·파랑)이 전쟁하는 코믹 SM 대환장 이야기. 출시 계획 없음. 수위는 이중의미·소품·소리 중심의 비노골 코미디.

## 폴더
| 경로 | 내용 | 주 담당 |
|---|---|---|
| `game/index.html` | 게임 엔진 전체(단일 HTML 캔버스) | **Claude** |
| `game/*.png *.webp *.jpg` | 영웅·적·엄폐물·배경 에셋(평면 구조, 파일명 그대로 참조) | GPT(추가), Claude(참조 수정) |
| `data/` | 대사·아이템·스테이지 데이터(JSON). 스키마는 `data/SCHEMA.md` | GPT(채우기), Claude(스키마) |
| `scenario/` | 시나리오 원고 11개 장(Markdown) + 문체 기준서 + 시놉 | Claude(원고), GPT(변환) |
| `assets_src/` | 케인이 만든 원본 시트(로고·이펙트·키아트·UI). 자르기 전 원본이라 삭제·이름 변경 금지 | 케인(추가), Claude·GPT(자르기) |
| `docs/` | 설정집 PDF | 참고 |
| `inbox/` | Claude와 GPT가 서로에게 남기는 작업 요청과 결과 | 둘 다 |
| `HANDOFF.md` | 협업 규칙과 작업 보드 (**작업 전 반드시 읽기**) | 둘 다 |

## 실행
`game/index.html`을 브라우저로 열면 됩니다. GitHub Pages를 켜면(Settings → Pages → main / root) 주소에서 바로 플레이하고 저장도 유지됩니다. 실행 경로는 `/game/` 입니다.

## 사람(케인)이 할 일
1. Claude 또는 GPT에게 "`HANDOFF.md` 읽고 `inbox/for_{나}.md`의 첫 항목부터 해 줘"라고만 말하면 됩니다.
2. 작업이 끝나면 상대 AI에게 같은 문장으로 넘기면 됩니다. 중간에 작업 중인 GPT에게 말을 걸지 않습니다.
