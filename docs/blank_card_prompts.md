1. 공방장 휴가 안내판 / 2. 초록색 검수 도장만 찍힌 빈 상자 / 3. 행방불명 마계 우편 소포 / 4. 톱니가 빠진 기계식 추첨기 / 5. 꽝을 축하하는 꽃폭죽 / 6. 빈 군수품 금고 / 7. 껍질만 번쩍이는 보물 상자 / 8. 다음 기회라고 적힌 듯한 접힌 카드(실제 글자는 넣지 말 것)
