## 공식
- 최대 Lv.99, Lv.1 초기 XP=0.
- Lv. L → L+1 요구량 = `300 + 60×(L−1)` 경험치.
- Lv.99 누적 XP = **314,580**.
- 공격력과 체력 성장 배율 = `1.015^(Lv−1)`. Lv.99 배율 ≈ **4.3020배**.
- 장비 공격력 옵션, 챕터별 아군 보너스, 포로 +20% 보너스는 **상호 곱연산**. 원래 방어력 계산·포로 고유 방어력 보너스는 변경하지 않음.
- 레벨 성장분은 `gmFor()`의 공격 배율 및 `launch()`의 캐릭터 생성 직후 `heroes[i].max / hp`에 반영. 중간 전투 레벨업으로 현재 HP가 변하지 않으며 다음 출격부터 적용.

## 경험치 보상
- 출전 편성 3명에게 **동일 XP**를 지급(막타·무기군·스킬 종류 무관).
- 클리어 시 기본 EXP는 스테이지별 제한 시간(프레임)/3600×100을 반올림한 값. 실제 소요시간에 보상을 비례시키지 않아 일부러 시간을 끌어도 XP가 늘어나지 않음.
- 스테이지 추천 레벨(실제 출입 제한 없음) = `min(99,1+round((tier×10+stage−1)×1.6))`. F1~F5의 1~50편 = 대략 1~79레벨, 마계(C11) 마지막 편 ≈95레벨.
- 파티 평균 레벨과 추천 레벨 차이 보정 = `clamp(1+0.012×(추천−파티평균), 0.45, 1.20)`. 고레벨의 저난이도 반복 파밍은 효율이 낮고, 적정·상위 난이도는 조금 더 유리함.
- 실패 시 XP는 기본의 최대 25%, 처치 비율에 비례. 한 스테이지에서 클리어/실패 결과 XP 지급은 한 번만 처리.
- 첫 클리어뿐 아니라 이미 완료한 **반복 미션도 같은 원칙으로 경험치 지급**.
- 이론적인 기준 플레이 속도 100 XP/분이라면 **52.43시간**. 실제 클리어 속도·재도전·매칭 난이도 보정·이동 및 메뉴 시간에 따라 실제 99레벨까지 소요 시간은 달라지므로 실기 테스트로 보정해야 함.

## 난이도 성장 V1
- 기존 장(章)별 적 HP 배율 `1.60^tier` → `1.64^tier`.
- 기존 장(章)별 적 공격 배율 `1.35^tier` → `1.39^tier`.
- 장 내 스테이지별 적 보정, 스폰, 엄폐·회복·보스 기본 구조, 아군 챕터별 성장·장비·정화방 및 스킬 쿨다운 미변경.
- 이는 즉각적인 전체 리밸런싱이 아닌 가파른 중·후반을 위한 **작은 1차 보정**; 실기 결과에 따라 수치만 되돌리거나 추가 보정 가능.

## UI / 오펜스 연동
- 출격 편성 카드 좌상단, 장비 목록 초상화 좌상단에 작고 **동그란 숫자 아이콘**만 표시(레벨 텍스트/경험치 바는 넣지 않음).
- 전투 결과에 출전 3명 공동 경험치 지급과 레벨업 인원을 표시.
- 장차 팔라독형 오펜스에서도 영웅 키(ROSTER.k)를 공통 ID로 사용하고 `window.GW.leveling`을 참고한다:
  - `level(key)`, `totalXP(key)`, `thresholds`, `multiplier(key)`, `recommended(ch,no)`, `xpToNext(key)`, `grantXP(keys,amount)`.
  - 오펜스 특유의 전투 피해 판정은 별도 계산하되 기본 **레벨·공격력·체력 성장 배율**은 동일하게 한다.
  - 오펜스는 아직 이 API와 연결하지 않았고 게임별 보상 중복 지급 방지 정책은 통합 시 검증 필요.
