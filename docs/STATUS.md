# GENDER WARFARE 작업 현황 (2026-10-08 기준)

## 1. 역할과 작업 방식
- **케인**: 방향 결정, 이미지 제작(배경·오브제·적·영웅·UI·FX 시트), 테스트 플레이.
- **Claude**: 엔진·UI·밸런스·에셋 가공(자르기·색 입히기)·검증·커밋/푸시·테스트 zip 전달.
- **GPT**: 분량 큰 글 작업(아이템 이름, 꽝 카드 문구 등). 요청은 `inbox/for_gpt.md`, 보고는 `inbox/for_claude.md`, 기록은 `inbox/log.md`.
- **작업 규칙(케인 지시)**: 존댓말·한국어만 / 도구 쓰기 전 한 줄로 하려는 일 말하기 / 수정 요청은 모아서 **한 번에** 반영(말 끝날 때마다 바로 고치지 않기) / 지어낸 설정·수치는 **가안** 표시 / 수치 조정은 체력·공격 등 묶어서 일괄 / 토큰 많이 쓸 작업은 먼저 말하기 / 영웅·화면을 프레임에 억지로 맞추지 않기(발 잘려도 됨).
- **검증 방식**: 헤드리스 크롬(Playwright)으로 장별 전투 화면 캡처 → 확인 → 커밋·푸시 → `gw_test.zip` 전달. 폰 FPS는 케인이 확인.
- **에셋 도구**: `tools/` — `build_btn.py`(흰 버튼 시트→국가별 색), `build_covers.py`(오브제 시트→장별 엄폐물·잔해·폭발물, `game/csets.js` 생성), `build_fx.py`(FX 시트→`game/fx_*.webp`), `slice_objs.py`(번호표 자르기), `replace_hero_poses.py`, `md2json.py`. 원본 시트는 `assets_src/`.
